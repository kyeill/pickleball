🔄 Sync from DUPR▾

Pull in your latest matches whenever you’ve played. The sync runs in your own browser while you’re logged in to DUPR, so no DUPR token is stored anywhere.

One-time setup (desktop Chrome): drag this button to your bookmarks bar → 🔄 Sync to Pickleball and delete any old “Copy DUPR token” bookmark. This browser also needs GitHub connected: Filters → ⚙ Clean up data → Save / sync → Connect GitHub.

  1. Open dashboard.dupr.com and make sure you’re logged in.
  2. Click your 🔄 Sync to Pickleball bookmark. This app opens in a new tab and shows progress (about half a minute).
  3. It saves automatically and opens the updated app. Other devices get the new data about a minute later.

Pop-up blocked? Allow pop-ups for dashboard.dupr.com and click the bookmark again.
